# ascii-sharks (vendored)

This directory contains the TypeScript canvas animation from
[stackedlol/ascii-sharks](https://github.com/stackedlol/ascii-sharks), adapted for the StudyFlow landing page.

The renderer palette was changed from multiple saturated hues to charcoal, silver and ice-blue so it matches StudyFlow's near-black design. The animation engine, species and simulation logic remain based on upstream.

The upstream MIT license is included in [LICENSE](./LICENSE). No runtime dependency was added.
